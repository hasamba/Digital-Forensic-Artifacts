# 093 - TrickBot, Cobalt Strike, PyXie, and SharpHound

Lab-safe companion to [Tricky Pyxie](https://thedfirreport.com/2020/04/30/tricky-pyxie/). It preserves `dmndfkle.exe` and its published hashes, TrickBot's Unicode `CmdValidate` relocation, `svchost.exe`/`wermgr.exe` injection ancestry, `man6` configuration, one-hour recon delay, three-day beacon dormancy, the `wermgr.exe` → `cmd.exe` → hidden PowerShell Cobalt chain, Amazon malleable profile and `192.169.6.180`, the complete published recon list, empty SAM/SYSTEM/SECURITY save canaries, the signed-LogMeIn/PyXie lineage, `benreat.com` TLS keepalive metadata, `SharpHound.exe NoSaveCache`, a generated BloodHound archive, daily registry-save telemetry, and the report's no-final-objective outcome. Ransomware is only the report author's hypothesis and is not simulated.

Run elevated with the standard lab gate via `.\TrickyPyxieSim-Complete.ps1 -LabConfirmed`; artifacts remain under `%PUBLIC%\TrickyPyxieSim`, and cleanup is separate. All executable-looking artifacts are signed `cmd.exe` fixed-echo decoys. IOC hashes remain metadata and never describe the decoys. No malware download, process injection, encoded PowerShell, real reconnaissance, registry/SAM access, credential access, directory collection, external connection, or ransomware action occurs; real DCs are refused.

Observed behavior maps to T1036, T1055, T1059.001, T1059.003, T1071.001, T1573.002, T1518.001, T1082, T1016, T1049, T1087, T1135, T1069.002, T1003.002, T1003.004, T1574.002, T1105, and T1482. These mappings are analyst inferences because the source provides no ATT&CK table.
